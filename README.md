### A full featured REST API for expenses application using Go, gorm, MySQL, Redis, in a MVC like architecture built on top of standard http package.

### API request documentations are at /bruno. open the /bruno as collection in Bruno Desktop app or VS Code extension.

### API reference: [docs/api.md](docs/api.md)

### Run demo

```sh
git clone <repo>
cd demo
go run .
```

### Run frontend
```sh
cd client
live-server
```
